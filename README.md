# sunbrand

Portfolio website of Karen Janssen, live at sunlightbrand.de. Plain HTML and CSS, no build step, no CMS.

## Structure
- `index.html` – home: profile, case-study slides, archive
- `gear-s/index.html` – case study: Navigation for Samsung Gear S
- `assets/` – images used on the site

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish
Hosted on GitHub Pages from the `main` branch. Every change merged into `main` goes live.
